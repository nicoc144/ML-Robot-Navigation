Project Proposal Midterm Report Final Report

Robotic Maze Navigation through Supervised and Unsupervised ML

Team Members: Nicolas Caballero, Vladyslav Havriutkin, Andrew Li, Evan Rosenthal, Rakesh Shankar

1. Introduction / Background

Literature Review

Robotic maze navigation often relies on classical algorithms like A* or Dijkstra, which require full map knowledge and struggle with sensor noise. To improve generalization, supervised models like Random Forests [1] and Neural Networks [2] map sensor inputs to actions. Additionally, unsupervised methods like PCA, K-Means, and Gaussian Mixture Models [3] reduce high-dimensional sensor data into meaningful states. This project compares these paradigms to predict expert navigation commands from local data.

Dataset Description

The dataset is self collected using a PD controlled expert robot. Each sample contains robot heading, raycast distance values, and a discretized command label derived from wheel velocities: forward, left, right, backward. All features are numerical. Preprocessing includes scaling, dimensionality reduction, and class balance analysis.

2. Problem Definition

Problem

Classical navigation algorithms such as A* and Dijktra's are limited by their reliance on deterministic transitions. Our objective is to develop a machine learning-based control policy for a differential-drive robot that utilizes rangefinder sensor data to navigate unknown mazes.

3. Methods

Simulation & Data Generation

We implement a physics-based simulation in PyBullet consisting of a procedurally generated 2D maze and a differential-drive robot with forward-facing raycast sensors. Expert trajectories are generated using classical path planning (A* and wall-following) followed by a PD waypoint-tracking controller. During execution, we record:

  • Raycast sensor distances
  • Goal-relative heading
  • Discrete action (Forward, Turn Left, Turn Right) derived from controller angular velocity

At test time, the learned policy outputs one of the three discrete actions, which are mapped to fixed wheel velocities. To reduce distribution shift, we introduce controlled perturbations including waypoint jitter, steering noise, sensor noise, and randomized start/goal configurations.

Supervised Learning: Imitation-Based Navigation

Navigation is formulated as a supervised classification task: 

[Sensor Readings, Goal Heading] -> Discrete Action

We evaluate three models implemented in scikit-learn:

  • k-Nearest Neighbors (KNN) [4]
  • Random Forest Classifier [5]
  • Multi-Layer Perceptron (MLP) [6]

Performance is measured using action accuracy, confusion matrices, maze success rate, collision rate, and path efficiency relative to the expert.

Unsupervised Learning: Structural Discovery

To identify recurring geometric patterns, we cluster expert sensor observations without action labels. We evaluate:

  • K-Means [7]
  • Gaussian Mixture Models (GMM) [8]
  • Principal Component Analysis (PCA) for visualization [9]

Clustering quality is assessed using Silhouette Score and Bayesian Information Criterion (BIC). We analyze whether clusters correspond to structural primitives (e.g., corridors, intersections).

Integration Study

Baseline:   Sensor + Heading -> Action
Enhanced:   Sensor + Heading + Cluster ID -> Action

Cluster assignments are appended as features to evaluate whether structural abstraction improves generalization and navigation performance on unseen mazes.

Preprocessing

  • Domain Randomization: Diverse maze layouts and start/goal positions.
  • Noise Injection: Small perturbations during expert rollout.
  • Feature Normalization: Z-score scaling of inputs.
  • Parallel Data Collection: Multiple PyBullet instances in DIRECT mode.

4. (Potential) Results and Discussion

Evaluation Metrics (Supervised)

  • Accuracy: The percentage of the total timestamps where the model's predicted actions match the PD controller's actions.
  • Precision: The ratio of correct action predictions to total predictions, where high precision minimizes false turns into walls.
  • Recall: The ratio of identified correct actions to total actual actions, where high recall means less missed turns
  • F1-Score: The harmonic mean / the balance between "missed turns" and "wrong turns."
  • ROC-AUC: Indication of class separation. A higher AUC score means better class separation

Evaluation Metrics (Unsupervised)

  • Silhouette Score: Evaluates a model based on how well-defined clusters are in space. A score for each point is calculated based on the distance to points inside its cluster versus points in neighboring clusters/
  • Bayesian Information Criterion: Useful for GMM, calculates probability that a point belongs to a distribution. This metric also heavily penalizes overfitting.

Project Goals

For classification accuracy, we'd ideally want to have a classification accuracy of at least 80%, this need to be high to account for the dominant "forward" class. The F1 score should also be greater than 0.75 to ensure that the robot attempts a required turn. For unsupervised learning, we're aming to a Silhouette Score that shows strong structural definition (around 0.5 or higher) to ensure that the clusters are well defined. We recognize PyBullet training's energy cost, although the required compute remains lightweight.

Expected Results

Between the supervised models, we expect the MLP to achieve the highest classification accuracy and F1 score. We expect Random Forest to perform the second best, and we expect KNN to be the weakest performer.

For the unsupervised component, we expect K-Means and GMM to identify roughly 3 to 5 meaningful clusters. We expect GMM to outperform K-Means in states where there are wide corridors or angled turns. PCA is expected to reveal that the majority of variance in the raycast sensor space is captured in 2 to 3 principal components.

Finally, we expect the enhanced supervised model that includes cluster ID to outperform the baseline model on unseen maze layouts due to the extra information from the clusters.
